# 新規リポジトリへのプッシュ前レビュー

## 結果

追加の重大な不具合は見つからなかった。実装時レビューで指摘されたフィールドコードとObject継承プロパティの衝突は、Setへの変更と回帰テストで修正済み。

## 確認対象

- 組織・グループの拒否優先、許可のOR条件、既定表示、下位組織の判定。
- 不正設定、所属情報取得失敗、タイムアウト時の非表示。
- PC・モバイルの表示イベント、非同期処理と画面遷移の競合、レコード値を変更しないこと。
- 設定画面の保存・復元、削除済みコード、テーブル重複、HTMLとして解釈しない表示処理。
- 公式CLIで生成されたZIPの署名、プラグインID、マニフェスト、ソースとの一致、秘密鍵除外。

## 検証

- `npm test`: 37件成功。
- `npm run verify`: 成功。
- 配布ZIP・ID・SHA256だけをdist内のGit管理対象に追加。node_modules、署名用秘密鍵、その他のビルド生成物は除外。
- 新規クローンでは署名用秘密鍵を復元してから再ビルドする手順をREADMEに追記。

## 残る確認範囲

Kintone実テナントでのインストール、実API接続、必須項目を含む保存、実機モバイル、他プラグインとの共存は未検証。画面表示だけを制御し、CSVやREST API等の取得経路は制限しない。

## リポジトリ

ユーザーの追加依頼に基づき、GitHubに非公開リポジトリ `rapyutapazoo-design/kintone-table-visibility` を新規作成し、レビュー対象をmainへプッシュする。実装時の「Git未初期化・プッシュ未実施」という記録は当時の状態を表す。
